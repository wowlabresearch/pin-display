# Pin Display — web controller

InteractionSensing'26 · 4×4 Scotch-yoke pin matrix (ESP32-S3).

Hosted control page. Generated from `web/index.html` in the firmware project.

- **Laptop (hub):** open the page in Chrome/Edge, *Connect USB* to the ESP32, choose **02 iPhone Tilt**. It shows a room code + QR.
- **iPhone (controller):** scan the QR (or open the page and enter the code), tap *Start sensor*.
